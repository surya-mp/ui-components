# @sypra-ui/ui

## 0.4.0

### Minor Changes

- Add `@sypra-ui/ui/primitives` and `@sypra-ui/ui/widgets` entry points.
- Split form, display, layout, navigation, and feedback implementations into
  focused component modules while retaining compound composition helpers and
  root-package imports.

## 0.3.0

### Minor Changes

- Add accessible combobox, radio group, OTP input, toggle, segmented control,
  collapsible, scroll area, and queued toast primitives.
- Add a V8 coverage command and behavioral coverage for shared primitives.

## 0.2.0

### Minor Changes

- Add FormField, SettingRow, and ConfirmActionDialog alongside responsive component layout improvements.
